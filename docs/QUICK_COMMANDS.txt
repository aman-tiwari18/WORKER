================================================================================
QUICK COMMANDS REFERENCE
================================================================================

MAIN SERVER SETUP (After pushing to VM):
================================================================================

1. Make executable:
   chmod +x setup_main_server.sh script-server/setup_worker.sh

2. Run setup:
   sudo ./setup_main_server.sh

3. Grant MySQL access:
   mysql -u root -p
   GRANT ALL PRIVILEGES ON cctv_monitoring.* TO 'root'@'%' IDENTIFIED BY 'rootpassword123';
   FLUSH PRIVILEGES;
   EXIT;

4. Install dependencies:
   cd cctv_backend && npm install
   cd ../script-server && pip install -r requirements.txt

5. Start PM2:
   cd .. && pm2 start ecosystem.config.js && pm2 save

6. Verify:
   pm2 status
   curl http://localhost:8000/health
   sudo exportfs -v

================================================================================
WORKER SETUP (On each GPU system):
================================================================================

1. Copy folder:
   scp -r /path/to/cctv/script-server user@worker-ip:/home/user/

2. Run setup:
   cd /home/user/script-server
   sudo ./setup_worker.sh <id> <main_ip> <start> <end>

   Examples:
   sudo ./setup_worker.sh 2 192.168.1.100 5001 10000
   sudo ./setup_worker.sh 3 192.168.1.100 10001 15000
   sudo ./setup_worker.sh 4 192.168.1.100 15001 20000

3. Verify:
   curl http://localhost:8000/health
   docker logs cctv_script_server_worker_2

================================================================================
VERIFICATION COMMANDS:
================================================================================

Main Server:
  pm2 status
  sudo systemctl status nfs-kernel-server
  sudo exportfs -v
  curl http://localhost:8000/health

Workers:
  docker-compose -f docker-compose.worker.yml ps
  df -h | grep nfs
  curl http://localhost:8000/health
  docker exec cctv_script_server_worker_2 nvidia-smi

================================================================================
TROUBLESHOOTING:
================================================================================

NFS Issues:
  sudo systemctl restart nfs-kernel-server
  sudo exportfs -ra

MySQL Issues:
  sudo systemctl restart mysql
  mysql -h 127.0.0.1 -u root -p -e "SELECT 1"

PM2 Issues:
  pm2 logs
  pm2 restart all

Worker Connection:
  telnet <main-ip> 3306
  showmount -e <main-ip>
