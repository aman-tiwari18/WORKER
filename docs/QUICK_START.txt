================================================================================
HORIZONTAL SCALING - QUICK START
================================================================================

WHAT YOU NEED TO DO:
================================================================================

1. MAIN SERVER (Do this first):
   
   a) Setup NFS:
      sudo apt-get install -y nfs-kernel-server
      sudo mkdir -p /mnt/nfs/cctv_images
      sudo chmod 777 /mnt/nfs/cctv_images
      echo "/mnt/nfs/cctv_images *(rw,sync,no_subtree_check)" | sudo tee -a /etc/exports
      sudo exportfs -ra
      sudo systemctl restart nfs-kernel-server
   
   b) Start services:
      docker-compose up -d
   
   c) Verify:
      docker-compose ps
      sudo exportfs -v

2. WORKER NODES (Do this on each GPU system):
   
   a) Copy script-server folder:
      scp -r user@main-server:/path/to/cctv/script-server /home/user/
   
   b) Run setup (ONE COMMAND):
      cd /home/user/script-server
      sudo ./setup_worker.sh <worker_id> <main_ip> <cam_start> <cam_end>
   
   Examples:
      Worker 2: sudo ./setup_worker.sh 2 192.168.1.100 5001 10000
      Worker 3: sudo ./setup_worker.sh 3 192.168.1.100 10001 15000
      Worker 4: sudo ./setup_worker.sh 4 192.168.1.100 15001 20000
   
   c) Verify:
      curl http://localhost:8000/health
      docker logs cctv_script_server_worker_2

================================================================================
CAMERA DISTRIBUTION (20K cameras example):
================================================================================

Main Server:  1 - 5,000
Worker 2:     5,001 - 10,000
Worker 3:     10,001 - 15,000
Worker 4:     15,001 - 20,000

Each worker automatically processes ONLY its assigned cameras.

================================================================================
THAT'S IT!
================================================================================

All workers connect to:
- Main server MySQL (port 3307)
- Main server NFS (/mnt/nfs/cctv_images)

All detection images saved to shared NFS storage.
All results written to central database.
Frontend shows results from all workers.

================================================================================
TROUBLESHOOTING:
================================================================================

Can't connect to MySQL?
  sudo ufw allow from 192.168.1.0/24 to any port 3307

NFS mount fails?
  sudo systemctl status nfs-kernel-server
  sudo exportfs -v

GPU not detected?
  docker run --rm --gpus all nvidia/cuda:12.2.0-base-ubuntu22.04 nvidia-smi
